# Portfólio — Lucas Gomes Paz

Portfólio pessoal responsivo desenvolvido com HTML, CSS e JavaScript para apresentar minha trajetória na área de tecnologia, habilidades e projetos práticos.

🔗 **Acesse online:** https://lucasgomesbit.github.io/NOME-DO-REPOSITORIO

## Funcionalidades
- Alternância entre tema escuro e tema claro (com salvamento automático).
- Menu responsivo para dispositivos móveis.
- Seção de habilidades com foco no aprendizado prático de cada tecnologia.
- Cartões de projetos com acesso direto aos repositórios no GitHub.
- Links diretos para contato via LinkedIn, GitHub e Instagram.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Estrutura do projeto
- `index.html` — estrutura e conteúdo do site.
- `css/style.css` — identidade visual, layout e responsividade.
- `js/script.js` — alternância de tema, menu mobile e ano automático.
- `assets/lucas-perfil.png` — foto de perfil do portfólio.
